定位：把“开发者亲自验证后的 AI 工具判断”写成可检索、可复用的中文长文，而不是泛 AI 资讯或工具 README 的翻译。

1. [[01-写作与发布方法论]]：公众号长文的叙事、包装、发布和复盘原则。
2. [[02-Skill地图]]：每个环节该调用什么 Skill，哪些只是候选。
3. [[03-模板/公众号选题与证据包模板]]：动笔前先建立材料与边界。
4. [[03-模板/公众号发布卡模板]]：发布前把事实、图片、设置和链接一次确认。
5. [[03-模板/公众号48小时复盘卡模板]]：把反馈变成下一篇的证据。
6. [[04-案例与稿件索引]]：回到真实稿件和成品，而不是只看抽象方法论。
7. [[05-Skill与流程变更日志]]：记录“什么有效、为什么改、如何复验”，避免工作流悄悄漂移。

## 主流程

```text
信号与真实摩擦
-> 选题闸门
-> 证据包
-> 核心判断与文章结构
-> 成稿与标题候选
-> 排版、图片与手机预览
-> 人工发布
-> 48 小时复盘
-> 更新选题、模板或 Skill 候选
```

## 这套系统的三条纪律

- 先有现场、机制、证据、选择规则和边界，再谈文笔与包装。
- Skill 负责稳定的重复工序；选题判断、最终取舍和发布按钮保留人工闸门。
- 每次修改模板、方法或 Skill，都必须留下原因和下一次验证方式。
