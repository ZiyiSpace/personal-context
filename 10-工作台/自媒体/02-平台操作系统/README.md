这里按平台沉淀内容方法、工作流、Skill 映射、模板、案例和复盘。它不存放正在写的稿件，也不复制每个 Skill 的原始说明；稿件继续留在 `自媒体/04-公众号稿件/`，外部资源继续留在 `自媒体/06-资源链接/`。

跨平台任务先回到 [[../00-内容系统总控]]，再进入本目录的具体平台入口。

## 公共层的边界

- `自媒体/00-账号定位/`：长期定位与账号表达。
- `自媒体/03-内容工作流/`：跨平台共用的选题、证据、转译与内容资产方法。
- `自媒体/04-公众号稿件/`：实际生产中的稿件、排版 HTML 和配图资产。
- `自媒体/06-资源链接/`：外部项目、Skill 和网页资料的客观资源卡。

平台文件夹只回答：在这个平台上，什么内容值得做、怎么做、用哪些能力、发布后如何更新下一次判断。
