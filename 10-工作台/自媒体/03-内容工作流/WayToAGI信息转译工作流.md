# WayToAGI 信息转译工作流

创建日期：2026-07-12

## 目标

把 WayToAGI、X、GitHub、产品官网、论文/博客里的 AI 信息，转成你自己的内容资产。

重点不是“搬运”，而是：

```text
发现信号 -> 判断价值 -> 亲自验证 -> 转成人话 -> 结合你的项目/身份/场景输出
```

## 信息二道贩子的升级版

低级搬运：

```text
某工具发布了，大家快去用。
```

高级转译：

```text
某工具发布了。我试了 30 分钟，发现它真正适合的是 [人群/场景]。
如果你是学生/产品新人/自媒体创作者，可以这样用：
1. ...
2. ...
3. ...
但它现在还有这些坑：
1. ...
2. ...
```

## 每条信息的 7 个判断问题

看到一条 AI 信息后，先问：

1. 这是真的新东西，还是旧东西换壳？
2. 它解决了什么具体问题？
3. 普通人能不能用？
4. 学生/产品新人/自媒体创作者能怎么用？
5. 我能不能 30 分钟内亲自试一下？
6. 它和我的哪个项目/经历有关？
7. 它能不能变成教程、清单、避坑、复盘或观点？

## 内容转译模板

### 模板 1：新工具试用

```text
我今天试了 [工具名]。

一句话判断：
[你的结论]

它适合：
- ...
- ...

它不适合：
- ...
- ...

我会怎么用：
1. ...
2. ...
3. ...
```

### 模板 2：信息筛选

```text
今天看到 5 条 AI 信息，我只建议你关注第 2 条。

原因不是它最火，而是它最可能改变 [具体场景]。
```

### 模板 3：产品视角拆解

```text
这个 AI 工具看起来很强，但我更关心 3 个问题：

1. 用户是谁？
2. 高频场景是什么？
3. 它比现有工作流少了哪一步？
```

### 模板 4：学生场景转译

```text
如果你是学生，这个工具不要拿来炫技。

更实际的用法是：
1. 做课程项目 Demo。
2. 做简历作品集。
3. 做社团/活动自动化。
4. 做自己的内容生产系统。
```

## 每日工作流

### Step 1：收集

信息源：

- WayToAGI 公开内容。
- X 上 AI Builder / Indie Hacker / AI Coding 账号。
- GitHub Trending。
- Product Hunt。
- YouTube AI 教程。
- 小红书/抖音同领域爆款。

每天只选 5 条，不要无限刷。

### Step 2：筛选

只保留满足至少 2 个条件的信息：

- 和 AI Coding / Agent / 自媒体工作流有关。
- 你能亲自试。
- 能结合你的经历库。
- 能讲给普通人听。
- 有明确结果或反差。

### Step 3：验证

最低限度验证：

- 打开官网/仓库。
- 看一遍 demo。
- 亲自跑一个最小案例。
- 记录一个优点、一个坑、一个适用场景。

### Step 4：改写

不要直接翻译原文。改成你的视角：

```text
它是什么 -> 我试了什么 -> 我发现什么 -> 你可以怎么用 -> 我不建议谁用
```

### Step 5：分发

同一条信息分发成：

- X：短观点或 thread。
- 小红书：图文清单。
- 抖音/视频号：一分钟口播。
- YouTube：完整教程。
- Obsidian：沉淀为长期素材。

## 第一周任务

### Day 1

主题：搭建自媒体知识库。

输出：

- X：我为什么要公开搭建自己的 AI 自媒体知识库。
- 小红书：从 0 搭建 AI 自媒体知识库，我会分这 5 个区。
- 抖音/视频号：别一上来追热点，先搭内容母库。

### Day 2

主题：WayToAGI 信息转译。

输出：

- X：今天从 WayToAGI 看到 3 条信息，我只保留 1 条。
- 小红书：AI 信息太多看不过来？我用 7 个问题筛选。
- 抖音/视频号：普通人学 AI，最怕不是慢，是乱。

### Day 3

主题：经历库变内容库。

输出：

- X：我发现自己的经历库其实就是内容母库。
- 小红书：学生做自媒体没内容？先翻自己的项目经历。
- 抖音/视频号：你不是没内容，你是没把经历拆成选题。

### Day 4

主题：AI Coding 第一个实战。

输出：

- X：我用 Codex/Claude Code 做了一个小页面。
- 小红书：不会代码怎么开始 AI Coding。
- 抖音/视频号：AI Coding 不要先学语法，先做一个真实小东西。

### Day 5

主题：复盘。

输出：

- 哪个平台反馈最好。
- 哪个标题最容易让你讲顺。
- 哪类内容你最愿意持续做。
