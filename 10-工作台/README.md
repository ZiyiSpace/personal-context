# 王子怡工作台

本目录与个人档案共用同一个私有仓库，用于存放每天变化的选题、研究、草稿和正在推进的工作。

## 从哪里开始

- 新的零散想法或暂未分类任务：写入 `00-Inbox/`。
- 已经开始推进的非自媒体任务：在 `01-进行中/` 下新建项目目录。
- 临时草稿：写入 `02-草稿/`。
- 已交付且仍需跨电脑访问的文件：移入 `03-已完成/`。
- 自媒体新选题：更新 `自媒体/03-内容工作流/选材池.md`。
- 自媒体任务开始前：先读 `自媒体/00-内容系统总控.md`。
- 不再活跃但需要保留的材料：移入 `99-归档/`，不要直接删除。

## 稳定信息与动态工作的边界

- 仓库根目录的 `01-个人档案` 至 `06-当前状态` 是稳定、已确认的信息。
- `10-工作台` 是动态工作区，允许频繁更新。
- 工作中发现的新个人事实，先写入根目录 `08-待处理收件箱/`，本人确认后再更新正式档案。

## 安全边界

不要写入公司内部文档、客户数据、账号密码、Cookie、Token、API Key、登录状态、身份证件、合同、付款信息或未经授权的第三方个人信息。公司任务只能记录公开、脱敏且确认允许带离的信息。

当前迁移的是便携核心文本子集。部分 Obsidian 双链仍会指向未上传的本地素材、成品或资源卡；遇到缺失链接时先标记，不要虚构内容或自行从公司电脑补传敏感文件。
