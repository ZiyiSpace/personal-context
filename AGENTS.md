# Personal Context Agent Protocol

## Scope

This repository is a portable, sanitized context layer for Wang Ziyi. It is not the complete Obsidian vault and is not a credential store.

## Before substantial work

1. Read `START_HERE.md`.
2. Read only the task-relevant files.
3. Treat dated facts as potentially stale and verify them when the current state matters.

## Editing rules

- Preserve confirmed facts and evidence boundaries.
- Put unconfirmed additions in `08-待处理收件箱/`.
- Record confirmed material changes in `09-更新记录/`.
- Never add credentials, authentication states, private keys, cookies, tokens, contracts, identity documents, confidential employer information, or private third-party data.
- Do not upload or publish repository contents without Wang Ziyi's explicit authorization.
- Do not delete historical material merely to make the repository cleaner.

## Writing style

- Default to concise, natural Chinese.
- Lead with the requested decision or deliverable.
- Keep claims evidence-bounded and distinguish current fact, proposal, prototype and shipped behavior.
