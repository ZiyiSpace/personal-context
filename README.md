# 王子怡｜Personal AI Context

这是王子怡的便携式个人 AI 上下文库，用于在经过授权的电脑和 AI 工具中快速恢复个人背景、项目状态、作品信息与协作方式。

## 使用入口

1. AI 或协作者首先阅读 [`START_HERE.md`](START_HERE.md)。
2. 再根据当前任务读取相关目录，不要默认扫描无关内容。
3. 新产生但未经本人确认的信息，先写入 `08-待处理收件箱/`。
4. 只有在王子怡明确确认后，才能更新正式个人档案、经历、项目状态或对外口径。

## 目录

- `01-个人档案/`：个人定位、能力和已确认成果。
- `02-项目索引/`：代表项目的简要事实与公开边界。
- `03-作品链接/`：GitHub、作品集和在线 Demo。
- `04-职业材料/`：脱敏后的简历与申请材料原料。
- `05-工作偏好/`：AI 协作、写作和事实边界。
- `06-当前状态/`：当前阶段、方向与待确认事项。
- `07-工作流/`：读取、更新和交接规则。
- `08-待处理收件箱/`：新内容暂存区。
- `09-更新记录/`：重要变更记录。

## 安全边界

本仓库不得保存密码、Cookie、Token、API Key、私钥、身份证件、合同、付款资料、原始私人聊天、公司内部文档或未经授权的第三方个人信息。
